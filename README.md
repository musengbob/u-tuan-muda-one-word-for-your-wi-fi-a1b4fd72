The entry word is **"Buffering"** — the one word every Wi-Fi user has lived. It is the spinning wheel, the frozen video, the page that will not load, compressed into a single instantly readable network name. Funny because it is true: you join "Buffering" and immediately know what you are in for.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```

This writes the word to `output/entry.txt` (no trailing newline) and validates it: byte-identical to the intended word, exactly one word with letters only, within the competition's length limit.
